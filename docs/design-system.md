# MicCast 设计系统

两端（Windows / HarmonyOS）共用同一套 token 与交互规则。**改数值只改这里，两端一起改。**

单位：Windows 用 pt / 逻辑像素（96 DPI 基准），HarmonyOS 用 fp / vp。
**圆角、间距、颜色两端取同一数值；字号要换算（pt ≈ px × 0.75），见 §5。**

---

## 1. 设计原则

| 原则 | 含义 |
|---|---|
| **一个状态，两种说法** | 同一语义（接收中 / 未启动 / 错误）在两端用同一组颜色和同一套文案结构 |
| **克制用色** | 主色只用于「可执行的主操作」和「活跃指示」。红色只留给破坏性动作，不作为普通按钮 |
| **层次靠留白不靠线** | 分隔优先用间距，边框只做卡片轮廓（1px） |
| **动效短且只用于因果** | 状态切换 120ms，布局展开 200ms。不做装饰性循环动画 |
| **数字要稳** | 会跳动的数值用等宽数字，且右对齐或固定宽度，避免宽度变化带得整行抖 |

## 3. 圆角

| token | 值 | 用途 |
|---|---|---|
| `radius-pill` | **固定高度的一半**（26 高 → 13） | 状态胶囊、徽章 |
| `radius-hero` | `22` | 顶部 Hero |
| `radius-card` | `16` | 卡片、日志框 |
| `radius-control` | `10` | 按钮、输入框、下拉框 |
| `radius-small` | `6` | 轨道、小色块 |

> 禁止出现 token 之外的值。原来手机端有 3/9/12/13/18/24 六种散值，已归并到上表。

## 4. 间距

4 的倍数。不允许 token 之外的值。

| token | 值 |
|---|---|
| `space-1` | 4 |
| `space-2` | 8 |
| `space-3` | 12 |
| `space-4` | 16 |
| `space-5` | 20 |
| `space-6` | 24 |
| `space-8` | 32 |

约定：

- `page-padding` = **20**（窗口/页面左右边距）
- `card-padding` = **16**（卡片内边距）
- `card-gap` = **12**（卡片之间）
- `icon-text-gap` = **8**（图标与文字）

> **ArkUI 注意**：给块级容器设 `margin` 做左右留白时，不能同时写 `.width('100%')` ——
> 那样宽度会撑满父容器再被 margin 推出去，两边直接被裁。
> 用 `calc(100% - 40vp)`、或外层包一层带 `padding` 的容器。详见 AGENTS.md 6c。

## 5. 字体

**单位不同要注意**：WinForms `Font` 用的是 **pt**（1pt = 4/3 px @96dpi），ArkUI `fontSize` 用的是 **fp**（≈ px）。
所以两端**不能取同一个数值**，要按「视觉像素接近」对齐。下表左列是像素当量。

| token | ≈px | Windows (pt) | HarmonyOS (fp) | 字重 | 用途 |
|---|---|---|---|---|---|
| `font-hero` | 22 | `17` | `22` | Bold | 品牌名 |
| `font-metric` | 20 | `15` | `20` | Bold | 核心指标数字 |
| `font-title` | 13 | `10` | `13` | Bold | 卡片标题、主按钮文字 |
| `font-body` | 12.7 | `9.5` | `13` | Regular | 正文 |
| `font-label` | 12 | `9` | `12` | Regular | 标签、胶囊文字 |
| `font-caption` | 11.3 | `8.5` | `11` | Regular | 说明、单位 |

规则：

- **会跳动的数字用等宽字体**（Windows: `Segoe UI`；HarmonyOS: 默认数字已接近等宽，保持 `fontWeight Bold` 即可）
- 单位文字（帧/秒、kbps、毫秒）一律用 `font-caption` + `text-muted`
- 中文字体：Windows `Microsoft YaHei UI`，HarmonyOS 系统默认
- 圆角和间距两端可直接取同一数值（WinForms 逻辑像素 ≈ ArkUI vp）

## 6. 动效

| token | 值 | 用途 |
|---|---|---|
| `dur-fast` | `120ms` | hover / 按下 / 颜色切换 |
| `dur-base` | `200ms` | 展开收起、电平跟随、区段插入 |
| `ease-out` | `Curve.EaseOut` / 每帧插值 0.4 | 所有出现与数值追赶 |

**不做**循环动画、不做装饰性位移。状态变化必须有原因。

## 7. 交互逻辑：状态 → 视觉

两端共用。改映射只改这张表。

| 状态 | 状态胶囊 | 主按钮 |
|---|---|---|
| 未启动 | 半透明白底 + `on-hero` 字，文案「未启动」 | 主色填充「开始接收 / 启动麦克风服务」 |
| 已发现、等待连接 | 同上，文案「已发现手机 / 等待电脑」 | 保持不变（可点） |
| 接收中 | 同上，文案「接收中 / 正在串流」 | **描边中性**「停止接收 / 停止」 |
| 重连中 | 同上，文案「重连中」 | 描边「取消重连」 |
| 错误 | 同上，文案「连接失败」 | 主色「重试」 |

> 胶囊放在 Hero 渐变底上时**不用语义色**（绿/红在饱和渐变上对比度不足），统一半透明白底 `#33FFFFFF` + 白字。
> 语义色改由**主按钮形态**和**文案**承担。胶囊出现在非渐变底上的场景（未来如有）才用语义色 12% 底 + 语义色字。

按钮状态：

| 态 | 主色按钮 | 描边按钮 |
|---|---|---|
| 常态 | `accent` 填充 | 透明底 + `border` 描边 |
| 悬停 | `accent-hover` | `surface-alt` 填充，描边加深 |
| 按下 | `accent-pressed` | `surface-alt` 填充，描边加深 |

> 描边按钮的边框不能只用 `border`（浅色下淡到像禁用），要往文字色借约 50%。

## 8. 界面结构（两端对齐）

```
┌─ Hero（渐变，圆角 22）──────────────────┐
│  品牌图标 + 名称 + Tagline      状态胶囊 │
│  ── 连接后追加 ──                       │
│  麦克风输入                              │
│  ▓▓▓▓▓▓░░░░░░░░  电平条                  │
│  [指标1]      [指标2]      [指标3]       │
└─────────────────────────────────────────┘
┌─ 主操作区 ──────────────────────────────┐
│  [主按钮]            [增益控件（仅 PC）] │
└─────────────────────────────────────────┘
┌─ 端特有配置 ────────────────────────────┐
│  PC：手机 / 输出设备 / 手动 IP           │
│  手机：采集模式                          │
└─────────────────────────────────────────┘
┌─ 说明（可折叠）──────────────────────────┐
│  PC：缺虚拟声卡时的引导卡片              │
│  手机：「电脑上怎么用」步骤              │
└─────────────────────────────────────────┘
┌─ 日志（可折叠）──────────────────────────┐
└─────────────────────────────────────────┘
```

**指标优先级**：PC = 帧/秒、kbps、毫秒缓冲；手机 = 已串流时长、帧/秒、kbps。

## 9. 组件规范

### 卡片
- 底 `surface`，圆角 `radius-card`，描边 1px `border`
- 内边距 `card-padding`
- 不用阴影（深浅色下阴影都不稳定）

### 状态胶囊
- 高 **26**，圆角 **13**（= 高度一半），文字 `font-label`，内边距横向 `space-3`
- **不要写 `CornerRadius="999"`**：WinUI 的 `Border` 不钳制半径，四段圆弧会重叠成
  纺锤形；WinForms 的 `AddArc` 会自动收敛，所以从 WinForms 照搬 999 会画错
- Hero 内版本用半透明白底（`#33FFFFFF`）+ `on-hero` 文字

### 主按钮
- 高度 44，圆角 `radius-control`，文字 `font-title`
- 宽度：PC 固定 150；手机撑满可用宽度

### 指标
- 数字 `font-metric`，单位 `font-caption` + `text-muted`
- 多列时用等分列宽，数字左对齐（读起来稳定）

### 电平条
- 高 6，圆角 `radius-small`
- 轨道 `track` / `hero-track`；填充用 `ok → accent` 渐变（PC）或纯白（Hero 内）
- 跟随用 `dur-base` + `ease-out`

### 档位选择器（PC 采集模式无，手机有两档）
- 外框圆角 `radius-control`，底 `surface-alt`
- 选中项：底 `accent`，字 `on-accent`
- 切换过渡 `dur-fast`
